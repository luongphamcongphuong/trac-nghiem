# Trắc nghiệm

Đây là ứng dụng trắc nghiệm chạy trực tiếp trên trình duyệt.

## Đưa lên GitHub Pages

Các file `index.html`, `manifest.webmanifest` và `sw.js` phải nằm ngay thư mục gốc repository.

Trong GitHub:
- Settings → Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

File Excel `mau_excel_ngan_hang_cau_hoi.xlsx` nếu đang có dữ liệu riêng của bạn thì giữ nguyên file hiện tại trong repository; không dùng file mẫu khác để ghi đè.
