# Web Trắc nghiệm đa thiết bị

## Cách đưa lên web
1. Tải toàn bộ thư mục này lên GitHub Pages, Netlify, Vercel hoặc hosting có HTTPS.
2. Mở URL của website trên điện thoại/máy tính.
3. Có thể chọn "Thêm vào màn hình chính" trên điện thoại để dùng như ứng dụng.

## Lưu ý
- Ứng dụng đọc Excel trực tiếp trên trình duyệt.
- Người dùng có thể import file `.xlsx`, `.xls` hoặc `.csv`.
- Không cần máy chủ cơ sở dữ liệu cho chức năng hiện tại.
- Để import Excel, thiết bị cần truy cập được thư viện SheetJS từ CDN trong file index.html.
